# Cooperative Gig Services — SIH React Frontend

## Run
npm install
npm run dev

## Included
- Home page + attractive hero
- Services page
- 10 demo workers with names, ratings, jobs and cities
- Search, categories and rating filter
- Worker/service booking modal
- Login + signup
- Simple math CAPTCHA
- Current logged-in user's name appears in header
- Provider page protected by authentication
- Provider registration form
- Community interactive feed
- How It Works page
- About page
- OpenStreetMap + React Leaflet map with provider markers
- WhatsApp contact button for +91 93354 68985
- Responsive UI

Authentication in this prototype is frontend/localStorage only. For the SIH final build, connect it to your backend/JWT/database and use a server-side CAPTCHA/OTP provider for production.
